# Woordenlijst

Sommige alledaagse woorden hebben op Dodona een specifieke betekenis. Deze pagina definieert die termen in eenvoudige taal, in alfabetische volgorde. Bestaat er een uitgebreidere pagina over een term, dan linkt de definitie ernaar.

## Activiteit

Alles in een cursus waaraan je kan werken: een [oefening](#oefening) of een [leesactiviteit](#leesactiviteit). Activiteiten worden gegroepeerd in [reeksen](#reeks). Zie de [FAQ over oefeningen en leesactiviteiten](/nl/faq/activities/).

## API token

Een geheime code waarmee een externe toepassing of een script namens jou toegang krijgt tot Dodona, zonder je wachtwoord te kennen. Je kan een API token aanmaken in je profielinstellingen. Zie de [FAQ over API tokens](/nl/faq/api-tokens/).

## Cursus

De plaats waar een lesgever het leermateriaal voor één groep studenten verzamelt: een verzameling reeksen met activiteiten. Je registreert je voor een cursus om aan de activiteiten te werken en je voortgang bij te houden. Zie de [gids over cursussen](/nl/guides/students/courses/).

## Cursusbeheerder

Een gebruiker die een cursus beheert, meestal je lesgever. Cursusbeheerders kunnen de inhoud en instellingen van de cursus aanpassen, de oplossingen van alle cursusleden bekijken en ze verbeteren. Zie de [gids over cursusbeheer](/nl/guides/teachers/course-management/).

## Deadline

Een datum en tijdstip die een lesgever op een reeks instelt. Je kan na de deadline nog steeds indienen, maar enkel oplossingen die je voor de deadline indient, tellen mee om de reeks op tijd te voltooien. Zie [wat de statussen naast activiteiten betekenen](/nl/faq/activities/#wat-betekenen-de-statussen-naast-activiteiten).

## Evaluatie

Een hulpmiddel waarmee lesgevers de oplossingen voor een reeks nakijken: het verzamelt van elke student de laatste oplossing voor een deadline, zodat de lesgever ze kan overlopen, opmerkingen kan toevoegen en er optioneel punten op kan geven. Zie de [gids over verbeteren](/nl/guides/teachers/grading/).

## Judge

De software die je oplossingen voor een oefening automatisch controleert en de feedback genereert die je te zien krijgt, van een eenvoudig juist/fout-oordeel tot gedetailleerde testresultaten. Elke oefening is gekoppeld aan een judge, meestal eentje gemaakt voor een specifieke programmeertaal. Zie de [referentie over judges](/nl/references/judges/).

## Leesactiviteit

Een activiteit met enkel tekst om te lezen (in technische documentatie soms *content page* genoemd): er valt niets in te dienen en je markeert ze zelf als gelezen. Zie [hoe je een leesactiviteit als gelezen markeert](/nl/faq/activities/#hoe-markeer-ik-een-leesactiviteit-als-gelezen).

## Oefening

Een activiteit die je vraagt om een probleem op te lossen, meestal door code te schrijven. Telkens je een oplossing indient, controleert Dodona ze automatisch met een [judge](#judge) en krijg je meteen feedback te zien. Zie de [gids over oefeningen oplossen](/nl/guides/students/exercises/).

## Opgeslagen opmerking

Een opmerking die een lesgever heeft opgeslagen om te hergebruiken, zodat die snel dezelfde feedback kan geven op andere oplossingen waar ze van toepassing is. Zie [hoe je opmerkingen opslaat en hergebruikt](/nl/faq/annotations/#hoe-kan-ik-opmerkingen-opslaan-en-hergebruiken).

## Oplossing

Eén poging om een oefening op te lossen. Telkens je op `Indienen` klikt, bewaart Dodona je code als een nieuwe oplossing en laat het de judge ze controleren; je kan je eerdere oplossingen en hun feedback altijd opnieuw bekijken. Zie de [gids over feedback begrijpen](/nl/guides/students/feedback/).

## Opmerking

Een commentaar bij de code van een [oplossing](#oplossing), meestal bij een specifieke regel. Lesgevers voegen opmerkingen toe om je feedback te geven op je code, en vragen die je zelf over je code stelt, verschijnen op dezelfde manier. Zie de [FAQ over vragen en opmerkingen](/nl/faq/annotations/).

## Reeks

Een geordende groep activiteiten binnen een cursus, bijvoorbeeld een reeks per week of per onderwerp. Een reeks kan een [deadline](#deadline) hebben. Zie de [gids over reeksen beheren](/nl/guides/teachers/exercise-series-management/).

## Repository

Een Git-repository met de bronbestanden van oefeningen en leesactiviteiten. Lesgevers die hun eigen activiteiten opstellen, beheren die in een repository, en Dodona houdt de activiteiten op het platform ermee in sync. Zie de [gids over oefeningen opstellen](/nl/guides/exercises/creating-exercises/).
